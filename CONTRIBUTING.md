# Guide de contribution

Merci de contribuer au POC SAHAM.

## Principes
- Garder les changements **petits, ciblés et documentés**.
- Ne pas modifier le périmètre fonctionnel sans validation.
- Préférer des messages de commit explicites.

## Workflow recommandé
1. Créer une branche de travail.
2. Implémenter la modification minimale nécessaire.
3. Vérifier localement :
   - `npm run build`
   - `npm run lint` (si pertinent pour votre changement)
4. Mettre à jour la documentation si le changement impacte la compréhension du projet.

## Bonnes pratiques de revue
- Décrire le **contexte**, le **changement**, et l’**impact**.
- Ajouter des captures si l’UI est modifiée.
- Signaler explicitement les limites connues.
